# ADR-0012: Keycloak native SCIM per enterprise realm

Status: Accepted · Date: 2026-11-02

## Context

Enterprise customers want user provisioning from Entra ID or Okta.

## Decision

Enable Keycloak's native SCIM for enterprise realms only. The SCIM credential is scoped to one realm, so it cannot touch other tenants.

## Alternatives considered

- Our own SCIM server: more code and more risk, for no gain over the native support in 26.8.

## Consequences

- Not available to Standard tenants.
- Guides for Entra ID and Okta ship in Phase 5.
